# Airullez - Architecture Skill

This skill provides architectural guidance and design patterns for software development projects.

## When to Use
Use this skill when you need:
- System architecture design
- Design pattern recommendations
- Code structure organization
- Technology stack decisions
- Scalability planning
- Integration patterns

## Instructions

### 1. Architecture Assessment
- Analyze the current project structure
- Identify architectural patterns in use
- Evaluate scalability concerns
- Review technology choices

### 2. Design Recommendations
- Suggest appropriate design patterns
- Recommend code organization strategies
- Provide integration approaches
- Consider performance and maintainability

### 3. Implementation Guidance
- Provide concrete code examples
- Suggest file structure changes
- Recommend best practices
- Include testing strategies

## Resources
- Reference any architectural diagrams in `diagrams/`
- Code templates in `templates/`
- Configuration examples in `examples/`

## Usage
Invoke this skill by asking for architectural advice or design guidance for your project.
