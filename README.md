# Chess Master Pro - Professional Chess Application

A world-class chess application with professional UI, advanced AI, and comprehensive features.

## 🎯 Features

### 🎮 **Game Features**
- **Professional Chess Board** - Traditional wooden piece styling
- **Advanced AI** - Multiple difficulty levels (Beginner to Grandmaster)
- **Auto-loading Board** - Instant game start
- **Move Validation** - FIDE-compliant rules
- **Move History** - Complete game tracking
- **Timer System** - Chess clock functionality

### 🎨 **User Interface**
- **Navigation Tabs** - Play, Puzzles, Learn, Watch, Community
- **Responsive Design** - Works on all devices
- **Board Themes** - Classic, Wood, Marble, Green
- **Board Sizes** - Small and Medium options
- **Professional Styling** - Chess.com quality interface
- **Smooth Animations** - 60fps interactions

### 🧠 **AI Features**
- **Minimax Algorithm** - Advanced game tree search
- **Alpha-Beta Pruning** - Efficient computation
- **Position Evaluation** - Material, position, king safety
- **Multiple Levels** - 7 difficulty settings
- **Strategic Play** - Real chess understanding

## 🚀 Quick Start

### Prerequisites
- Node.js (for server version)
- Modern web browser

### Installation
```bash
# Clone the repository
git clone https://github.com/rlokesha/chess-master-pro.git
cd chess-master-pro

# For server version (optional)
cd chess-online
npm install
npm start
```

### Running the App
1. **Client Version**: Open `chess-online/public/professional-chess.html` in your browser
2. **Server Version**: Run `npm start` and visit `http://localhost:8080`

## 🎮 How to Play

1. **Start Game** - Board auto-loads with White to move
2. **Make Moves** - Click piece, then click destination
3. **AI Response** - Computer plays as Black
4. **Change Difficulty** - Select level from sidebar
5. **Customize** - Change themes and board size
